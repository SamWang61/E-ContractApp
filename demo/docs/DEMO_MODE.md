# 線上簽約示範模式（免登入）

## 這是什麼
`demo.html` + `demo.js` 是一個**純前端**示範頁：不需登入、不呼叫後端、不寄信，
一鍵產生甲／乙／丙三方的一次性簽署連結，可示範「簽署 / 退回修改 / 拒絕 / 連結失效 / 催簽 / 逾期」。
樣式沿用線上網站的 `styles.css`，外觀一致。

## 部署到 https://mycontractapp-911.web.app/demo.html
1. 把 `public/demo.html`、`public/demo.js` 複製到專案 Hosting 的 public 資料夾
   （與 `index.html`、`app.js`、`styles.css` 同一層）。`styles.css` 與線上版相同，可不覆蓋。
2. 在專案根目錄執行：
   ```
   firebase deploy --only hosting --project mycontractapp-911
   ```
3. 開啟 https://mycontractapp-911.web.app/demo.html

> 靜態檔案優先於 Hosting rewrites，所以不會被 `/sign/**` 之類的規則攔走；既有的正式流程完全不受影響。

## 注意事項（對客戶示範前請看）
- 資料存在**瀏覽器 localStorage**，不會進 Firestore。
- 簽署連結可傳給別人（手機、另一台電腦）開啟體驗；但「簽署進度」只會回寫到**產生連結的那個瀏覽器**。
  現場示範建議：管理者畫面開在簡報電腦，客戶用手機掃/點連結體驗簽署畫面，進度由你在簡報電腦上用「開新分頁簽署」補演。
- 頁面上已標示「示範模式・不具法律效力」，請勿當成正式簽署使用。

## 三分鐘示範腳本
1. 按「一鍵產生三方測試連結」。
2. 甲方：開新分頁 → 填姓名、勾同意（可手寫簽名）→ 確認簽署，回主頁看進度 1/3。
3. 乙方：「退回修改」（必填原因）→ 合約轉為「待修改」。
4. 丙方：「拒絕簽署」；或按「重設示範」重來，三方全簽完看到「已全數簽署」。
5. 再開一次已用過的連結，示範「Token 已失效」。
6. 「模擬到期提醒」看催簽信；「模擬逾期」讓待簽連結失效。

## 測試
`e2e.py`（Playwright）已涵蓋：產生連結、必填驗證、簽署、退回、拒絕、重複開啟、逾期、全數簽署、催簽、手機版。
