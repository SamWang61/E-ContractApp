    DEMO SCRIPT

    三分鐘簡報流程

    1. 按「一鍵產生三方測試連結」，說明三方各拿到專屬、一次性的簽署連結。
    2. 甲方：開新分頁 → 填姓名、勾同意 → 確認簽署，回到本頁看進度變成 1/3。
    3. 乙方：示範「退回修改」（必填原因），合約狀態轉為待修改。
    4. 丙方：示範「拒絕簽署」，或重設後三方全部簽完，看到「已全數簽署」。
    5. 重新開啟已使用的連結，示範「此 Token 已失效」。最後按「模擬逾期」收尾。
